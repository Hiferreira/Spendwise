# 💰 Spendwise

**Gaste com inteligência. Economize melhor.**

O Spendwise é um sistema de organização e planejamento financeiro pessoal desenvolvido em Python. Seu objetivo é ajudar os usuários a compreender melhor suas finanças, acompanhar despesas, analisar o comprometimento da renda e planejar a construção de uma reserva de emergência.

## 🎯 Objetivo do projeto

Desenvolver uma aplicação que permita visualizar a situação financeira mensal de forma clara, identificar compromissos financeiros e tomar decisões mais conscientes sobre o uso do dinheiro.

## ⚙️ Funcionalidades

- **Controle de renda:** registro do salário líquido e de rendas adicionais, como comissões.
- **Despesas fixas:** organização de moradia, alimentação planejada, transporte, saúde e educação.
- **Despesas variáveis:** registro de gastos com delivery, transporte por aplicativo, medicamentos, lazer e cuidados pessoais.
- **Compras parceladas:** cálculo do valor das parcelas e acompanhamento dos compromissos financeiros futuros.
- **Análise de dívidas:** registro de saldos devedores, juros e pagamentos obrigatórios.
- **Diagnóstico financeiro:** cálculo das despesas registradas, do percentual da renda comprometida e do saldo mensal estimado.
- **Reserva de emergência:** cálculo de metas financeiras com base nas despesas essenciais e estimativa do valor necessário para alcançar a meta.

## 🛠️ Tecnologias utilizadas

- Python 3
- Lógica de programação
- Variáveis e tipos de dados
- Estruturas condicionais (`if` e `elif`)
- Estruturas de repetição (`while` e `for`)
- Listas e dicionários
- Funções
- Tratamento de erros com `try` e `except`

## ▶️ Como executar

**Pré-requisitos:** Python 3 instalado e um editor de código, como o Visual Studio Code.

1. Clone este repositório:

   ```bash
   git clone https://github.com/Hiferreira/Spendwise.git
   ```

2. Acesse a pasta do projeto:

   ```bash
   cd Spendwise
   ```

3. Execute o programa:

   ```bash
   python SpendWise.py
   ```

   No Windows, também é possível utilizar:

   ```bash
   py SpendWise.py
   ```

## 📊 Como funciona

O usuário informa sua renda, registra as despesas e os compromissos financeiros e recebe um resumo da situação do orçamento. O sistema também permite simular contribuições para a reserva de emergência, considerando as informações fornecidas.

Os resultados dependem dos dados informados e servem como apoio à organização financeira pessoal.
